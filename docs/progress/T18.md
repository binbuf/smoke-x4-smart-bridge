## API facts for T19/T21/T27

- Mount over a `log_io_t`; geometry must be `sector_size == 4096` and
  `capacity` a whole number of sectors, 1..1,504. Sizes other than 4096 are
  rejected.
- `have_generation=true` is the normal boot path: pass the NVS generation.
  Old-generation sectors are ignored. Headerless sectors with valid records are
  adopted/reconstructed only in this mode.
- `log_ring_mount(..., false, 0)` on blank flash returns OK with
  `info.needs_format == true`. Generate a random u32, call
  `log_ring_format(ring, gen)`, then persist it to NVS **before** any writes.
  Format itself performs no erase; old sectors are reclaimed during rotation.
- `log_ring_append` assigns `rec->seq` (starts at 0). Any `SAMPLE_LOG_ERR_IO`
  sets `ring->failed`; call `log_ring_mount` again before retrying. Do not retry
  the same mount.
- `log_ring_read_seq` verifies record CRC/layout on every read; `ERR_RANGE`
  means the sequence is older than `min_seq`, newer than `max_seq`, or absent.
- `log_ring_info` is a no-I/O snapshot for `min_seq`/`max_seq`/`next_seq`/
  `generation`/`count`/`live_sectors`.

## Decisions / deviations

- Kept the ring in `log_core.c` as design 03 says (one file also owns the T17
  record codec). No new component file was needed; the IDF CMake already
  compiles `log_core.c`.
- `format` is lazy: it does not erase the whole partition. This avoids a
  multi-second boot erase; T19's `clear_pending` may erase old-generation
  sectors in the background.
- A sequence gap inside a sector is treated like a torn tail (stop scanning).
  The task only names bad CRC/sentinel; the gap check prevents a valid-looking
  stale record past a partial write from being adopted.
- Unknown-generation recovery chooses the header with the greatest `first_seq`.
  It can pick stale data if NVS is lost while unreclaimed old-generation sectors
  remain; NVS is the normal path. See ADR 0026.
- Header reconstruction is written and read back by mount. On real NOR a torn
  header may not be rewritable in place; the core fails the mount if the
  read-back does not verify. T19 decides whether to reclaim that sector.
