# T55 — Bench: all settings and actions

**Date:** 2026-10-28 · **Verification:** P (Pixel 11 Pro Fold + Heltec V3) ·
**Result:** partial pass. Every app-driven setting/action was walked on the real
bridge and phone, and two release defects were found and fixed. Three physical
checks remain (OLED photo, X4 SYNC re-pair, seeded `Not synced` gap); the
detailed evidence table is `artifacts/bench/T55/README.md`.

## What landed

- **Firmware fix (release-blocking):** `sample_log/log_flash_core.c` clear scan
  used a 4,096 B stack buffer on the 3,584 B `esp_timer`/main tasks. The first
  `clear_history` panicked (`InstrFetchProhibited`, PC `0x1000`) and every boot
  repeated it through `clear_pending`. It now scans in 256 B chunks. Retested
  clear, app-killed-mid-clear, and reboot-after-clear on the board. ADR 0060,
  design 03 §3.7.
- **App fix:** Setup scan rows printed the advertisement sentinels as
  `P4 -3277°F · 255%` after a blank/reset Bridge. `BridgeAdvertisement.preview`
  is now nullable and omits an invalid/detached temperature and unknown battery;
  `setup_codec_test.dart` covers invalid, detached and unknown-battery cases.
  Design 06 §6.4 updated.
- **Bench evidence** under `artifacts/bench/T55/` (release APK, serial logs,
  screenshots at 390/320 dp dark and light, backups/hashes in `backup/`).
- Release image: `02E2E2B4DA3013E14E3AED57A2D5505417B5214C263F2C7F43009ED3340F61F6`
  (603,472 B). Release APK:
  `2E095C5343D0D7350B574EE376A9E7D59963571745363296026ABD6B1505F28C`.

## Deviations / gotchas for later tasks

- **Do not restore a pre-run NVS image after re-pairing the phone.** It brings
  back a stale bond the phone no longer has and the app then loops on
  `disconnected reason 0x23d`. To finish this run the board was restored from
  the pre-run NVS+samples backup, phone bonds were cleared with a temporary
  one-time `bridge_config_clear_bonds()` boot call, the phone was re-paired, and
  the release image was reflashed. The final state has 1 bond, 1 X4 pairing, the
  pre-run generation/log, and a working link.
- A temporary `ESP_LOGI("BENCH passkey %s")` was used to read the OLED code while
  the webcam was black. Both temporary firmware changes are reverted; the
  committed image hash above is clean.
- `firmware/bench/t10_probe/tools/capture.py` can crash printing a replacement
  character to a cp1252 console. The capture file is still complete up to that
  line; prefer `python -X utf8 -m ...` or redirecting to a file.
- Opening `serial.Serial()` then setting DTR/RTS pulses EN and reboots the board.
  Set `dtr=False, rts=False` on the unopened `Serial()` object first.
- `wm density 540` gives 320 dp on this 1080 px phone; restore 390 after the run.
- The release APK is debug-signed, so `adb install -r` keeps app data/bonds.
- Clearing history runs on the timer task: keep the sweep buffer small (ADR
  0060). The bench retest, not the host suite, is the stack regression gate.
- Scan previews must omit sentinels; `-32767`/`-32768` and battery `255` are not
  temperatures/percentages.
