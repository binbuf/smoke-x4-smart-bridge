## What landed

- `app/lib/data/sync/archive_sync.dart`
  - `SyncStatus { idle, syncing, partial, complete, error }` and internal
    `SyncPhase { idle, recent, backfill, forward }`.
  - `ArchiveSyncCoordinator` over a `SyncTransport`; no timer and no BLE import.
  - `connectSync`: status request, empty-log completion, generation epoch reset,
    backward recent-first (32-record pages, 2,880 records), background backfill
    (64-record pages), forward catch-up from the local max.
  - `catchUp`: the existing 30 s path; refreshes status, resumes an interrupted
    backfill, then catches forward. All transport calls are serialised.
  - `recordLive`: appends by `seq`; cursor advances only for `cursorAfter + 1`.
  - `backfillDone` / `dispose` for tests and link teardown.
- `app/lib/data/db/sample_dao.dart`
  - `storeSyncBatch`: samples + gaps + both cursors in one transaction.
  - `updateSyncCursors`: nullable write that can clear cursors (unlike
    `SavedBridge.copyWith`).
  - shared `_insertRows` helper so there is one insert path.
- `app/lib/data/ble/bridge_protocol.dart`
  - `BridgeSyncAssembler` now rejects a non-contiguous `frame_seq` instead of
    concatenating a stream with a hole.
- `app/lib/data/ble/bridge_link.dart`
  - implements `SyncTransport`; archive mode replaces the 15-minute recent pass
    and owns the cursor. Live notifications are appended to the archive. One
    30 s timer and one live path remain.
- `app/lib/app/bridge_controller.dart` / `bootstrap.dart`
  - optional `SampleDao` creates the coordinator in production; `onBatch` feeds
    the approved History store, `onStatus` maps to `SyncState`.
- `app/lib/data/repository.dart`
  - `SqliteBridgeRepository.dao` exposes the archive DAO; `close()` delegates.
- Tests: `app/test/archive_sync_test.dart` (11), plus the new atomic DAO test in
  `local_database_test.dart`. `FakeBridge` now follows T39 forward/drained
  semantics (`seq > cursor`, drained is `ok`, only a whole empty log is

## Facts / gotchas for later tasks

- **T42:** read samples through `SampleDao.samplesInRange` / `extent`. Do not
  add another sync path or timer. `ArchiveSyncCoordinator.snapshot` exposes the
  current status, cursor and device extent.
- **T43:** `connectSync` is the reconnect path; it resumes an interrupted
  backfill when `cursor_before > device_min_seq`, then forwards. `catchUp` is
  the quiet 30 s pass and never shows the card.
- **T44:** after `deleteRange`, recompute or clear `cursor_before`/
  `cursor_after`; a deletion creates a local hole that the old cursors no
  longer describe.
- **Recent-first timing:** `connectSync` awaits only the 2,880-record recent
  pass. The rest runs in the background; tests await `backfillDone`.
- **Backward stop:** only `count == 0`. A backward request with cursor `0` is
  normal and returns count 0 after record 0 was fetched.
- **Forward cursor:** pass the local maximum `seq`, not `max_seq + 1`. The
  device returns `seq > cursor`; a duplicate at the cursor is rejected by the
  contiguity check.
- **Gap reason:** a device-reported forward gap uses `Not synced` (04 §4.6).
  Do not invent a reason for a time delta; that is a chart gap only.
- **Generation:** old generations stay in `sample`; the `bridge` row's
  `generation` and cursors describe the current segment.
- **Live:** live records before the first status/sync have no known generation
  and are skipped; the first sync fetch covers them.
- **frame_seq:** the assembler expects START at 0 and contiguous increments; an
  interleaved status response starts a new sequence.
