# T08 — CI

## What landed

- `.github/workflows/ci.yml` — six separately named jobs, all on every pull
  request (`pull_request`, `main` push, `workflow_dispatch`):
  1. `1 · protocol generate + drift check`: `make protocol`, then
     `git diff --exit-code -- protocol/gen`, `make protocol-check`, and
     `make protocol-test` (C + Dart vectors).
  2. `2 · C host tests`: CMake + Ninja + `ctest` on `firmware/test`.
  3. `3 · firmware build`: `espressif/idf:v6.0.2` container, `esp32s3`, the
     documented `sdkconfig.defaults;sdkconfig.defaults.heltec-v3` build, explicit
     `firmware/tools/check_image.py` re-run, image artifact upload.
  4. `4 · Flutter analyze/test (UI state matrix + layout)`: `flutter analyze`;
     named `test/view_state_test.dart test/ui_state_matrix_test.dart`; then the
     full `flutter test` suite (BLE fake included).
  5. `5 · UI screenshot/golden check`: `flutter test
     tool/ui_screenshots_test.dart` on `windows-latest`, pinned Flutter 3.47.8 so
     it compares on the platform that produced the baseline; failure images are
     uploaded.
  6. `6 · no-network/no-OTA dependency guard`: guard unit tests + real guard.
- `tools/ci/check_forbidden_deps.py`: rejects forbidden app packages in
  `app/pubspec.yaml` and the resolved `app/pubspec.lock` (so transitive packages
  count), release `AndroidManifest.xml` INTERNET/network/notification/foreground
  permissions, forbidden ESP-IDF components in `idf_component.yml` and
  `CMakeLists.txt`, and enabled Wi-Fi/IP/HTTP/MQTT/OTA
  `firmware/sdkconfig.defaults*` symbols. `legacy/`, `build/` and
  `managed_components/` are skipped.
- `tools/ci/test_check_forbidden_deps.py`: 9 unittest cases covering the clean
  tree, direct/transitive app packages, MQTT/OTA, firmware manifests, CMake
  components, comments, release permissions and Kconfig.
- `app/test/ui_state_matrix_test.dart`: seven stable states (Live, Live offline
  cache, History, History empty, Settings, Setup, Bridge details) × 320/390 dp ×
  dark/light, asserting the state marker and no overflow. CI job 4 names this
  file explicitly; T54 expands it.
- `app/tool/ui_screenshots_test.dart`: font root is now resolved from
  `FLUTTER_ROOT`, PATH, then common defaults, so the golden job works on both
  this bench and CI.
- Two layout fixes found by the new 320 dp matrix: the `ProbeCard` trend label
  now ellipsizes inside an `Expanded`; the empty History chart uses a
  `ConstrainedBox(minHeight: 300)` instead of a fixed `SizedBox` so the empty
  state can grow on a 320 dp phone. No golden changed.
- Docs: ADR `0019-six-job-ci-gate.md`; design 10 §10.1 pull-request CI table;
  screenshots README now says the baseline is a CI gate; root README CI note.

## Key facts for later tasks

- Workflow job IDs: `protocol`, `host-tests`, `firmware-build`, `app-tests`,
  `ui-goldens`, `dependency-guard`. Keep the display names stable; they are the
  failure-attribution boundary.
- Job 1 must generate *before* the check. The gate is `git diff --exit-code --
  protocol/gen`; `make protocol-check` alone also catches drift but does not
  prove the generator ran.
- Pinned versions: Flutter 3.47.8, Dart 3.13.7, ESP-IDF 6.0.2 (Docker tag
  `v6.0.2`). Updating either Flutter or ESP-IDF means updating the workflow and
  regenerating the goldens as a reviewed change.
- Goldens are platform-sensitive; they intentionally run on `windows-latest`.
  Local command: `cd app && flutter test tool/ui_screenshots_test.dart`
  (update only with `--update-goldens`).
- Guard command: `python tools/ci/check_forbidden_deps.py`; self-tests:
  `python -m unittest discover -s tools/ci -p "test_*.py" -v` (needs PyYAML).
- The guard reads the lockfile too, so a forbidden package arriving only as a
  transitive dependency still fails. If a legitimate BLE package pulls `http`,
  that is a design decision, not a guard exemption.
- The debug/profile Android manifests intentionally keep INTERNET for the
  Flutter tool; the guard checks only `src/main/AndroidManifest.xml`.
- CI does not build `legacy/`; do not add it to any path. `firmware/sdkconfig`
  and build dirs stay untracked.
- `app/test/ui_state_matrix_test.dart` has a private `_StateCase` table; add
  states there (or extend in T54) rather than duplicating pump/resize logic.

                                -> C tests exit 0; Dart protocol codec tests passed

cd app
flutter analyze                 -> No issues found!
flutter test                    -> 54 tests passed
flutter test test/view_state_test.dart test/ui_state_matrix_test.dart
                                -> 14 tests passed

                                -> Project build complete

Negative probes (files restored afterwards; `git diff` clean):

```text
append comment to protocol/gen/records.h; make protocol-check  -> exit 2, stale
add http to app/pubspec.yaml dependencies; guard               -> exit 1, forbidden package
replace app/screenshots/live_dark.png with live_light.png;
  flutter test tool/ui_screenshots_test.dart --plain-name "live dark"
                                                               -> exit 1, 100% pixel diff
```

The workflow YAML was parsed and its jobs are exactly
`app-tests, dependency-guard, firmware-build, host-tests, protocol, ui-goldens`
with an empty `pull_request` trigger.
