## Facts for later tasks

- **T37 evidence location is fixed:** `artifacts/bench/T37/`; the manifest is
  `artifacts/bench/T37/README.md`. Use one capture file per step.
- **Capture command** (from repo root) is
  `python firmware/bench/t10_probe/tools/capture.py --port COM5 [--reset] --out artifacts/bench/T37/<step>.log`.
  `--reset` pulses RTS/EN only; the helper holds DTR false so it never presses
  PRG/GPIO0. A USB power cut produces `# serial error: ...` and a clean close.
- **Power cut must cut both rails.** Pulling USB with the 3000 mAh pack
  connected leaves the bridge running. Disconnect the pack or use an inline
  switch; the pre-cut capture is `03a`, the power-on reboot capture is `03b`
  (no `--reset`).
- **Serial proof tokens:** boot `sx4.log.flash: recovered in ... state OK`;
  pairing `sx4.radio: pair ACK sent on <hz> Hz`; each accepted sample
  `sx4.sample: stored seq=<n> t=<a>,<b>,<c>,<d> flags=0x<hex>`.
- **Flags:** attach bits 0–3, clock-valid `0x20`, source-Celsius `0x40`,
  Billows-attached `0x10`. Detached temps are `-32768`; invalid-but-present is
  `-32767`.
- **Do not mark T37 rows PASS from host tests.** The host suites prove the code
  paths only; T37 owns the physical evidence.
- The stock receiver is independent; a T37 failure there is real and needs a
  named follow-up, not a waiver.
