## Facts / gotchas for later tasks
- The banner deliberately has no action. Do not add `Retry`/`Connect` there;
  put sync/reconnect once in Bridge details (T51).
- `SettingsViewState.connectionSummary` is the one offline summary. Reuse it.
- `Live change window` is local-only and does not touch stored samples or the
  OLED; T53 persists it with units and theme.
- Offline Bridge details already disables Bridge name, timeout and Smoke X4
  re-pair, and keeps `Forget this phone`. T52 owns the confirmation flows and
  `Bridge is off`; the current read-only test pins that split.
- The root's History group row is titled `Storage` under the
  `HISTORY & STORAGE` heading; the key `settings.history.logs` is unchanged.
- `SettingsTile` keys sit on the tile, so read-only assertions use
  `tester.widget<SettingsTile>(...).onTap == null` (buttons use `.onPressed`).
