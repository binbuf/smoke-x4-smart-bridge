# T05 — App skeleton

## What landed

- Production entrypoint: `app/lib/main.dart` → `app/lib/app/bootstrap.dart`.
  Bootstrap opens SQLite, builds the repository, initialises `BridgeController`
  and mounts `SmokeBridgeApp`.
- `app/lib/app/bridge_controller.dart` is now the single
  `BridgeController extends ChangeNotifier`; the prototype controller file was
  moved here and all widget/test/tool imports were retargeted.
- `app/lib/data/repository.dart`: `BridgeRepository` seam,
  `SqliteBridgeRepository`, `EmptyBridgeRepository` and `BridgeSnapshot`.
- `app/lib/data/db/app_database.dart`: `AppDatabase.open()` /
  `openInMemory()` (sqflite), with injectable `DatabaseFactory` and path.
  `schemaVersion = 1`; T40 owns the schema/migrations and must bump this.
- `app/lib/app/smoke_bridge_app.dart`: MaterialApp with the approved theme and
  `AppShell`; Live/History/Settings stay `NavigationBar` + `IndexedStack`.
- Android-only target: removed tracked `app/web/` and `app/windows/`, removed
  web/windows from `.metadata` and `analysis_options.yaml`, updated `app/README.md`.
- Workflow: root `Makefile` gained `app-analyze`, `app-test`, `app-check`
  (`FLUTTER` defaults to `flutter.bat` on Windows).
- Tests: new `app/test/app_skeleton_test.dart` covers the Live shell launch,
  controller↔repository initialisation/close, the SQLite open path, repository
  counts, and that the production entrypoint files do not import `prototype/`.

## Gotchas for later tasks

- **T06**: screens still import `app/lib/prototype/fixtures.dart` transitively
  (Live sparklines and the History fixture builder). The production entrypoint
  itself does not import `prototype/`, but the widget graph still does. Replace
  those reads with view state and remove fixture values before release.
- The `BridgeRepository` currently only returns a `BridgeSnapshot`
  (`readingCount`, `lastReadingAt`). `SqliteBridgeRepository` tolerates a missing
  `sample` table, so it returns empty until T40 creates it.
- T40 must decide whether to keep `AppDatabase.schemaVersion = 1` (empty DB) or
  bump it and add `onCreate`/`onUpgrade`; existing dev installs may already have
  an empty version-1 file.
- T07 should inject its BLE fake through `BridgeController`/bootstrap without
  changing `main.dart`.
- T08 CI should call `make app-check` (or the two Flutter commands) and needs to
  run `flutter pub get` first.
- `sqflite_common_ffi` is a dev dependency used only by host tests; production
  uses `sqflite`.
