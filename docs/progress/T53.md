- **One conversion + formatting layer** (`app/lib/app/formatters.dart`)
  - `toDisplayTemperature` / `toDisplayTemperatureDelta`, `temperatureValue`,
    `temperatureText`, `temperatureDeltaText`, `unitLabel`.
  - `intl` number and date formatting; `commaInt` is locale-aware
    (`128,430` / `128.430`), `storageSizeLabel`, `clockLabel`, `chartTime`,
    `shortDate`, `shortDateWithYear`, `monthShort`, range/date labels.
  - `clockLabel` chooses a 24-hour or 12-hour CLDR pattern; no production
    `AM`/`PM` literal remains outside intl patterns.
- **Controller/view-state seam**
  - `BridgeController` exposes `localeName` + `use24Hour`,
    `applyPlatformFormatting` and `repaintForFormatting`; all counts, storage
    and Bridge reading dates format through them.
  - `HistoryViewState.withUnits` re-presents an already-loaded view.
  - Probe tiles, sparklines, History chart/summary/Cook view, Billows target,
    confirmations, storage counts and the OLED preview all consume the same
    helpers/pre-formatted state.
- **Persistence** (`AppPreferences`, schema v3 `preference`)
  - Keys: `appearance.theme_mode`, `preferences.temperature_units`,
    `preferences.live_change_window_minutes`.
  - `prepareLaunch` → `loadLocalPreferences` restores theme, units and change
    window before the first frame. Bridge `config` adoption persists the
    adopted unit too.
  - `setTempChangeWindowMinutes` clamps 1–60 and persists.
- **Same-frame repaint**
  - `HistoryViewLoader` no longer keys on units; it wraps the loaded view with
    `withUnits`, so Summary/chart change without a reload.
  - `PastCookScreen` mirrors the source controller's units, locale, 24-hour
    setting and change window through a listener.
  - `DevicePreviewScreen` wraps its body in `ListenableBuilder`.
- **Clock**: `BridgeLink` already sends `set_time` once in the connect path
  (`_prepareLink` → `_setTimeIfNeeded`) with `unix_ms` + `tz_offset_min`, only
  when the force flag is set or `clock_valid` is false or drift > 2 s. T53 adds
  the sub-tolerance regression test; first-connect body assertions already
  existed in `bridge_link_test.dart`.
- **Tests**

## Facts / gotchas later tasks

- Add `intl` formatting via `formatters.dart`; do not reintroduce local
  `* 5 / 9` in widgets. Stored °F is canonical (`tempF`, `valueF`).
- `Intl.defaultLocale` is set in `bootstrap` and by `SmokeBridgeApp` from
  `PlatformDispatcher.locale`; 24-hour comes from
  `PlatformDispatcher.alwaysUse24HourFormat`. A locale/24h change schedules
  `controller.repaintForFormatting()` after the delivery frame.
- `HistoryViewLoader` intentionally does not reload on units. If a future
  presentation field is added, re-wrap the loaded view instead of adding it to
  the loader key.
- `PastCookScreen` copies the source controller. Any new presentation state
  added to `BridgeController` must be mirrored in `_syncPresentation`, or the
  open Cook view will freeze it.
- Preference keys are strings in the existing `preference` table. Do not create
  a second table.
- Unit changes write the whole Bridge `config` through T51's read-modify-write;
  offline they are queued in `_pendingUnitsWrite` and flushed on the next
  healthy connect. `config.units` is the OLED source, not a sample field.
- Tests run `flutter pub get --offline` fine with `intl 0.20.2` already in the
  local pub cache.
