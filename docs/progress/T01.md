# T01 — Workspace scaffold and ignore rules

## What landed

- Root tree beside `legacy/`: `firmware/`, `protocol/` (`fixtures/`, `fixtures/lora/`,
  `gen/`), `tools/`. `app/` and `docs/` already existed and were left in place.
- Empty directories are tracked with `.gitkeep` (one per scaffold directory) so a
  clean clone sees the tree before T02–T05 add real files.
- Root `.gitignore` now covers: `build/`, `.dart_tool/`, `.gradle/`, Flutter/Dart
  plugin and coverage output, `firmware/sdkconfig` / `sdkconfig.old`,
  `managed_components/`, `dependencies.lock`, Android `local.properties` /
  signing files, `__pycache__/`, editor scratch. `legacy/` stays ignored.
- `docs/design/adr/0012-workspace-tree-layout.md` records the layout/ignore
  policy; `docs/design/README.md` gained a "Repository tree" section.

## Gotchas for later tasks

- **Do not ignore `protocol/gen/`.** Generated C/Dart codecs are committed and
  T02's `protocol-check` guards drift. Only add ignore entries for generated
  output that is explicitly *not* committed.
- `sdkconfig.defaults*` is deliberately **not** ignored; only local
  `firmware/sdkconfig` / `sdkconfig.old` are.
- `firmware/test/build` and `firmware/build` are covered by the bare `build/`
  pattern, so host test and ESP-IDF builds leave no untracked output.
- `app/` already contains the tracked approved prototype (105 files, its own
  `.gitignore` covers `.dart_tool/` and `/build/`). T05 replaces/extends it into
  the production app; it is not an empty scaffold.
- `legacy/` is ignored by git and is **local-only** (0 tracked files, 5866 files
  on this bench). A clean clone will not contain it. T03 must copy fixtures into
  `protocol/fixtures/lora/` while authoring, never read `legacy/` at build or
  runtime.
- `docs/*` is ignored with explicit negations. A new top-level file under
  `docs/` needs a matching `!docs/<name>` entry; files under `docs/design/`,
  `docs/tasks/`, `docs/progress/`, `docs/logs/` are already included.
