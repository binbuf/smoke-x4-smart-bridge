Physical cadence/page walk/PRG evidence is T37; USB-detached wake and currents
are T62. This task produced the template, extractor, golden gate and procedure.

## What landed

- `tools/bench/cadence_report.py` — parses a product serial capture
  (`sx4.radio: rx ...` + `sx4.sample: stored seq=...`) and falls back to the
  T10 probe's `state26` RX lines. Emits the markdown report from
  `artifacts/bench/T37/CADENCE-REPORT-TEMPLATE.md`.
  - samples = stored records (or T10 state frames), never sync/ACK;
  - intervals use ESP-IDF uptime within one boot; restarts are separate gap
    rows and never fabricate an interval;
  - expected = rounded capture wall time / 30 s (`# opened`/`# closed`), falling
    back to the first-to-last sample span with a warning;
  - RSSI is taken from the RX line immediately before the stored record;
  - sequence holes, missed samples, restarts and unexplained gaps are reported;
  - every radio gap starts as `_unrecorded — fill at T37_`.
- `artifacts/bench/T37/CADENCE-REPORT-TEMPLATE.md` — committed report contract:
  run conditions, packet/expected/interval/RSSI/missed-sample fields, gap-cause
  table, and the manual display/control checklist. All physical rows are `⏳`.
- `tools/bench/test_cadence_report.py` + `tools/bench/fixtures/product-cadence.log`
  — 11 unittest cases. The real T10 capture is parsed too: 41 state frames,
  one 166.34 s gap, RSSI −52…−28 dBm, interval 30.22/33.64/166.34 s.
- `firmware/test/test_ui_render.c` — `check_golden_coverage()` asserts one
  golden case per `UI_PAGE_*` and one per `UI_OVERLAY_MASK_*`. All 17 existing
  goldens still pass.
- `Makefile` — `make bench-test`.
- `.github/workflows/ci.yml` — bench tooling tests added to the host-tests job.
- `artifacts/bench/T37/CHECKLIST.md` — new step 6 (30-minute cadence) and step 7
  (page walk, sleep/wake, battery, PRG); close-out is now step 8.

## Facts for later tasks

- **T37 command sequence:** capture `06-cadence.log` for ≥30 min, then
  `python tools/bench/cadence_report.py artifacts/bench/T37/06-cadence.log
  --out artifacts/bench/T37/CADENCE-REPORT.md`. Fill only the run conditions,
  gap causes and manual rows; leave the measured columns alone.
- **Expected-count definition:** rounded capture wall duration / 30 s. If the
  capture lacks `# closed`, the tool falls back to the first-to-last sample span
  and says so under Warnings. Record which basis was used if it matters.
- **Restarts:** the log clock resets; the tool cannot know the downtime. It
  emits a restart gap row with an unknown duration and requires a cause.
- **RSSI matching:** one `sx4.radio: rx` line then one `sx4.sample: stored`.
  A stale RX line (>5 s) is not attached; missing RSSI is `—`.
- **Golden coverage:** adding a page or overlay without a `.fb` case now fails
  `ui-render` in `check_golden_coverage()`, not just the byte comparison.
- **T37 evidence names:** `06-cadence.log`, `CADENCE-REPORT.md`,
  `06-run-*.jpg`, `07-display.log`, `07-pages-*.jpg`, plus the sleep/wake/
  battery/PRG photos listed in the checklist.
- **No physical claims here.** The T37 `⏳` rows must stay `⏳` until the capture
  and photos exist; host tests only prove the code paths.
