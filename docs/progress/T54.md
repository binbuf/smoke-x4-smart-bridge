## Decisions
- Keep the copy gate on string literals, not raw source: comments, identifiers
  (`ProbeHealth.stale`) and `${view.rssi}` are not user copy. This is the narrow
  scan that can fail on a real injected word without false positives.
- “Records” is banned as the user noun; the approved 13 §13.4 sentence “The
  Bridge records whenever…” uses it as a verb and is allow-listed by exact
  phrase.
- Screenshot changes are gated by a manifest hash rather than by adding the
  golden suite to `flutter test`: the renderer stays the documented
  `--update-goldens` command, while the normal app suite notices any pending
  diff. See ADR 0059.
- Centralisation covers the shared T54 surfaces. A few one-off screen strings
  remain inline; new UI must use `AppStrings`.

## Facts / gotchas later tasks
- Run the screenshot sequence in this order after an intentional UI change:
  `flutter test --update-goldens tool/ui_screenshots_test.dart`,
  `dart run tool/screenshot_manifest.dart`, review the PNG diff. The manifest
  test compares both the PNG set and an FNV-1a hash; it deliberately fails until
  both commands run.
- `AppStrings` is in `lib/app/strings.dart`; copy lint scans the whole product
  UI layer, so adding a new banned word anywhere in a string literal fails even
  if a widget is not covered by the matrix.
- The copy scanner is char-based and handles single/double/triple quotes,
  escapes and both comment styles. It strips `${…}` before matching; keep
  identifiers out of copy assertions.
- `AppMotion.duration(context)` is the only approved transition helper. Do not
  add a raw duration for screen transitions; reduced-motion must stay zero.
- Light theme status/probe colours were changed for contrast. Regenerate
  screenshots whenever these tokens move.
- Matrix tests use `ValueKey` on each `MaterialApp` so a dialog from one
  width/theme iteration cannot leak into the next. Keep that when adding
  dialog states.
- `setup scanning`, `setup bonding` and `setup firstSync` set `settle: false`
  because their progress indicators animate forever; pump 400 ms instead of
  `pumpAndSettle`.
- Stable-key test order is Live → History → Settings because plain `tab =`
  assignment does not notify; use `controller.setTab`.
