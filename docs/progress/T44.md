## Facts / gotchas for later tasks

- **UI deletion:** always `planLocalDeletion(scope)` → show the plan →
  `applyLocalDeletion(plan)`. Do not re-plan between confirmation and delete.
- **No automatic deletion:** only an explicit `applyLocalDeletion` calls
  `deleteRange`. Launch, sync, generation change, factory reset and low storage
  never call it.
- **Exact ranges:** `deleteRange` is half-open. 30/90-day plans use `[0, cutoff)`;
  `all` uses `[0, 0x7FFFFFFFFFFFFFFF)`.
- **Gaps:** DAO removes gaps detected inside the deleted date range and
  trims/removes gaps overlapping the deleted sequence extent. The right-trim fix
  is in `SqfliteSampleDao.deleteRange`.
- **Cursors:** after deletion current-generation `cursor_before/after` come from
  its remaining extent; if none, both become `NULL`. This is intentional and
  lets the next sync refetch the current segment.
- **Storage used:** estimate `count * 72 B` (04 §4.9 midpoint). Not a file-size
  query; never used for cleanup.
- **Bridge figures:** from `stats`; `oldest_unix_s`/`newest_unix_s` are 0 when
  unknown, rendered `—`. Never substitute phone rows.
- **Bridge clear:** T44 still resets only displayed Bridge figures. T49/T52 own
  the real command/result and generation boundary.
