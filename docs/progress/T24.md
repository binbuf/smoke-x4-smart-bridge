## Chosen curve

Pack mV -> percent, descending:

`4200/100, 4100/90, 4000/80, 3900/70, 3850/65, 3800/60, 3750/50, 3700/40,
3650/30, 3600/20, 3550/15, 3500/10, 3450/7, 3400/5, 3350/2, 3300/0`

Interpolation rounds to the nearest percent. Above 4200 clamps to 100, below
3300 clamps to 0. `0 mV` returns 255. `0 %` is a valid empty-pack value.

## Facts for later tasks

- **Update the ratio in one place:** `BOARD_BATTERY_DIVIDER_X100` in
  `board/include/board_battery.h` (or `-DBOARD_BATTERY_DIVIDER_X100=...`).
  Default 490 is x4.9, not yet DMM-calibrated (T62).
- **Stats source:** `board_battery_stats_t` has `millivolts`,
  `adc_millivolts`, `percent`, `samples`, `failures`, `valid`. T47 can read
  `bridge_state_snapshot()` instead; both expose 255 for unknown.
- **Housekeeping is the only ADC caller.** Do not sample from the UI, radio or
  sample pipeline. If a new periodic job is added, extend `housekeeping.c` and
  keep `tasks.h` in sync.
- **`bridge_state_tick()` moved.** The log writer no longer calls it; avoid
  re-adding it (single-writer seqlock, ADR 0028).
- **A failed sample publishes UNKNOWN, not the last value.** This is deliberate:
  a stale pack voltage is worse than `—`.
- **Battery init failure is non-fatal.** `board_power_init()` still returns OK;
  the snapshot stays 255.
- **`adc_oneshot` needs `esp_adc` + `esp_rom`** in the board component's
  `PRIV_REQUIRES`; missing them is a link error.
- **UI does not wake for battery.** `ui_mark_dirty()` after a sample cannot
  turn a sleeping panel on (T22 rule).
