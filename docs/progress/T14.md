## What landed

- `firmware/components/sx_protocol/include/sx_protocol_types.h` - the
  `smoke_x_types.h` shape reworked: explicit unit suffixes (`temp_f10`,
  `alarm_*_deg`, `frequency_hz`), canonical `temp_f10`, sentinels
  `SX_PROTOCOL_TEMP_DETACHED`/`SX_PROTOCOL_TEMP_INVALID`, Billows candidate
  target plus `billows_target_valid`, and a counters struct.
- `firmware/components/sx_protocol/include/sx_protocol.h` - public API:
  comma counter, probe inference, sync/state parsers, ACK formatter,
  counters snapshot/reset. The ESP-IDF `sx_protocol_init()` declaration is
  behind `#ifdef ESP_PLATFORM`, so the host test compiles the same header
  with no `esp_err.h`.
- `firmware/components/sx_protocol/sx_protocol.c` - legacy parser port with
  `strtok_r`, strict numeric parsing, a fixed 128-byte stack buffer, and no
  heap. State parsing:
  - infers 2 probes from 16 commas and 4 from 26; everything else rejected;
  - requires one trailing comma, no empty fields and no trailing token;
  - compares the ID with `paired_device_id` before other fields and returns
    `SX_PROTOCOL_ERR_FOREIGN_DEVICE` + mismatch counter;
  - emits `temp_f10`; Celsius goes through `(C10*9)/5 + 320`;
    `source_celsius` is provenance only;
  - `state == 3` emits `TEMP_DETACHED` regardless of the frozen wire value;
  - preserves `new_alarm` and `billows_attached`;
  - probe 4 `max` becomes `billows_target_deg` only as an unvalidated
    candidate (`billows_target_valid == false`, relation owned by M5);
  - builds a local struct and copies to `*out` only on success.
- `firmware/components/sx_protocol/LICENSE` - MIT notice for the upstream
  smoke-x-receiver portions, retained alongside the source comments.
- `firmware/test/test_sx_protocol.c` - `sx-protocol` CTest. It replays all 21
  `parser-vectors.tsv` rows, every real capture (events, passive, first
  contact, t10) and the malformed capture. It asserts the named X4, Celsius,
  detached, Billows, foreign, alarm, X2-defensive and malformed cases,
  atomic rejection, counters (including the CRC hook) and ACK formatting.
- `protocol/fixtures/lora/parser-vectors.tsv` - added
  `billows-target-candidate` (single-probe-marker target shape); the real
  captures and reports were already committed by T03 and are unchanged.
- Docs: design 02 §2.5 parser contract + §2.9 suite pointer; design 03
  §3.6/§3.14; ADR 0022.

## Gotchas for later tasks

- Host path must stay IDF-free: `sx_protocol.h` exposes `esp_err_t
  sx_protocol_init(void)` only when `ESP_PLATFORM` is defined. Do not include
  ESP-IDF headers unconditionally in this component.
- `sx_protocol_parse_state(payload, paired_id, out)` infers probes from commas;
  there is no `num_probes` argument. `paired_id == NULL` disables the filter
  (sync discovery / corpus tests only). Pass the persisted ID in production.
- A foreign frame returns before numeric parsing; it is counted as
  `foreign_device_packets`, not `parse_failures`.
- `alarm_high_deg`/`alarm_low_deg` remain in the packet's active unit; do not
  put them straight into a °F record. Only `temp_f10` is canonical.
- `billows_target_valid` is always false in the MVP parser. T56/M5 owns the
  max↔target relation; until then show "Billows detected" only.
- Counters are plain globals with a single writer. If T21 moves parsing to a
  different task than housekeeping's reader, add a lock or snapshot discipline.
- ACK formatting counts an attempt; it does not transmit. T16 still owns the
  radio TX and the `sx_radio_set_frequency()` band check.
- Captures: `x4-t10-25min.loralog` contains an `rx ack2` frame from the stock
  receiver; replay code must skip 2-comma ACKs rather than feed them to the
  parser.
- Parser rejects `strlen(payload) >= 128`; test vectors with 128+ bytes are
  intentionally invalid.
