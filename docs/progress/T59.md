# T59 — Bench: Billows observation
**Date:** 2026-10-28 · **Verification:** P (Pixel 11 Pro Fold + Heltec V3 + real
Smoke X4 + real Billows) · **Result:** pass — M5 exit gate met.

Evidence: [`artifacts/bench/T59/README.md`](../../artifacts/bench/T59/README.md).

## What landed

- Flashed the T57 image (`B0E14F…70C39B1`, 603,472 B) over the T55 image and
  installed the clean T57 release APK (`3310BCE…D364F22`).
- Walked the real Billows matrix with the X4 at 225/250/275 °F, °F→°C→°F,
  detach, offline last-known, and a re-pair ACK.
- Committed 21 screenshots, 17 UI dumps, the serial capture and the app log
  under `artifacts/bench/T59/`.
- Recorded the results in `docs/hardware-verified.md`, the task and the roadmap.

## Result

- **225/250/275 °F:** app card showed `Set temp 225.0°F`, `250.0°F`,
  `275.0°F`; the serial frames had probe 4 `max` = the same target with
  `billows_attached=1`.
- **Units:** `275.0°F` → `135.0°C` after the Settings flip
  (`config applied: units 0`) → `275.0°F` after restoring °F
  (`units 1`). OLED matched.
- **Attach/detach:** card appears on attach; on detach the card is absent, one
  `Billows not detected` notice appears with `View connection log`, and the
  Settings screen shows `Lost this session`, `Last detected 3 min ago`, `—`
  target and the focused log.
- **Offline:** with Bluetooth off, `Last observed state`, `Set temp (last known)
  275.0°F`, `Last detected 1 min ago`, and the Billows log are visible.
- **OLED:** operator confirmed `DETECTED`, `SET 275°F` (and `135°C` in the unit
  flip), `Set on the Smoke X4`; no fan-running/duty claim.
- **Stock receiver:** kept updating throughout and after the re-pair.
- **TX:** the only TX line in the whole capture is
  `I (2312812) sx4.radio: pair ACK sent on 918500000 Hz` after
  `unpair_smoke_x: pairing cleared, scanning 915/920`. State frames resumed
  immediately. No target setter or control UI exists.

## Gotchas

- The `live` notification occasionally lagged a base change by up to ~2 min
  while the BLE link churned (`central disconnected reason 0x213`, reconnect,
  one `advertising start failed (6)`). A relaunch/read showed the correct target.
  The target did follow every setpoint; this is a T43/T46a live-refresh
  follow-up, not a T59 failure.
- The first 250 °F screenshot still showed 225 °F until the next read; the card
  was re-captured after the notification landed.
- Billows was detached and reattached once to capture both the lost UI and the
  offline last-known state.
- OLED evidence is operator-confirmed; no usable camera photo.
- A temporary `print()` in `_onLinkLive` produced the `T59 live target=…`
  lines in `app-live.log`; it was removed and the clean release APK
  (`3310BCE…`) reinstalled before the run closed. The UI code is identical.
- T66 owns the actual release-notes file. The required "Billows observed only;
  set the target on the Smoke X4" wording is fixed in the decision record and
  the product copy.
