- **Bridge reset:** recovered `seq 0..243`, next 244, state OK; the app
  auto-reconnected in 31 s with no passkey prompt (`pairing complete status 0,

- **MTU:** 247, protocol 1.0, firmware 0.1.0, 1/4 bonds.
- **Forced drop:** `Reconnecting` attempts, six-attempt exhaustion to `Can’t
  reach the Bridge`; bounded retry UI passed.
- **Quiet sync:** two `sync frame_seq`/`sync transfer ended` pairs 30.18 s

- **History:** real 24 h shell, four probes, Summary values from live data.
- **Billows:** absent with `caps.billows_observe = 0`.
- **Cold launch:** still Setup, as expected until T43.
