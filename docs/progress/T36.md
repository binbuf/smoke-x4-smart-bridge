## Gotchas for later tasks
- **Widget tests that drive the real link:** wrap the sync procedure in
  `tester.runAsync(...)`. In the `testWidgets` fake-async zone a bare
  `await link.connectAndSecure(...)` hangs on the fake client's
  `Future.delayed(Duration.zero)`.
- **Pending timers:** dispose the link (`await link.dispose()`) inside the test
  body; `addTearDown(controller.dispose)` alone can run after the timer check.
- **Store clock:** `RecentHistoryStore` takes `now`; the controller wires it to
  `content.now`. A fixed-time test must give its content the same fixed clock as
  the records and `BridgeLink.nowUtc`.
- **Fixture type split:** `BridgeSampleRecord` (app wire) vs `SampleRec`
  (generated test codec). `test/support/recent_history.dart` returns `SampleRec`
  for `FakeBridge`; map it to `BridgeSampleRecord` in store tests.
- **Empty semantics:** `hasAnyHistory` is store data or `historyHasData`.
  Defaults are honest (`false`); `demoBridgeController` opts in.
- **Custom range:** `entireHistoryRange` follows the store when records exist,
  so the custom sheet spans only the recent window in V0.
- **Only one gap band:** painter breaks at every >90 s hole, but only the widest
  hole gets the labelled band. Multi-band support is T42/T45.
