## What landed

- `app/lib/data/db/sample_dao.dart`
  - new `SampleDao.samplesAroundSeq(fromSeq, toSeq, bridgeId, generation)`:
    the newest stored reading at/before the gap and the oldest at/after it.
- `app/lib/data/history/history_archive.dart`
  - stored gaps are read with `dao.gaps()` and mapped by sequence → time with
    `samplesAroundSeq`; `detected_ms` is never a chart position.
  - one visible window supplies bands, inferred holes, cooks, cook-gap spans
    and `missingFromBridge`. Cooks scan only `[startMs, endMs)`.
  - a gap with no stored neighbours is skipped, not drawn at detection time.
- `app/lib/widgets/probe_chart.dart`
  - `historyGapBandRect` / `historyGapBandShowsLabel` (pure, testable):
    a minimum 2 px band, and `Not synced` is labelled even when narrow at 24 h.
- `app/lib/data/recent_history_store.dart`
  - `seed()` for the cold-launch backfill; `sparkline()` anchors its one-hour
    window at the newest stored reading when that is older than now.
- `app/lib/app/bridge_controller.dart`
  - `prepareLaunch` seeds sparklines from `SampleDao` after the newest-reading
    read (`_backfillLiveHistory`).
  - offline launch takes `deviceName`/`deviceId` from the saved `bridge` row;
    `savedBridgeShortId` (`AC:A7:…:82:76` → `8276`, unknown → `—`).
  - offline probe semantics say `last reading … ago, showing saved readings`
    and never `updated live`.
  - `blocked` clears `syncState`/progress in `_onLinkPhase`,
    `_applyPlatformBlocked` and `_onLinkBlocked`.
- `app/lib/features/live/live_screen.dart`
  - the sync card cannot render in `ConnectionPhase.blocked`.
- `app/lib/data/ble/bridge_link.dart`
  - `healthCheck` re-arms the `live` notification after its `live` read
    (`_resubscribeLive`), recovering a Bridge reboot that left the GATT link
    marked connected but dropped CCCD state.
- Tests added/updated:
  - `test/history_archive_test.dart` — stored-gap placement, inferred hole,
    range-scoped permanent-loss banner, full-ring/range-scoped cooks,
    `Since cook start` disabled with no cook. Updated the existing two-cook

  - `test/history_gap_chart_test.dart` — band geometry/label policy.
  - `test/live_backfill_and_identity_test.dart` — archive backfill (recent and
    6 h stale), no `No history yet`, saved identity not `A4F2`.
  - `test/live_screen_test.dart` — offline semantics, blocked sync card.
  - `test/launch_connect_test.dart` — blocked clears sync progress.
  - `test/bridge_link_test.dart` — reboot/notification-recovery path.
  - `test/support/fake_bridge.dart` — `smokePaired`/`smokeLive` knobs.

## Facts / gotchas for later tasks

- `SampleDao` has a `noSuchMethod` fallback in
  `test/history_archive_widget_test.dart`; new interface members still need a
  real implementation when the test asserts on them.
- `gapsInRange` still filters by `detected_ms` and remains the deletion/sync
  helper. History uses `gaps()` + `samplesAroundSeq`; do not switch History back
  to the detection-time query.
- A gap band needs at least one surviving neighbour row. Deleting both sides
  removes the band (the deletion service already trims/removes gap rows).
- `RecentHistoryStore.sparkline` now follows `newestAt`; the 15-minute History
  fixture window (`RecentHistoryStore.fixture`) is unchanged.
- The controller's fixture default `deviceId = 'A4F2'` still exists for review
  builds, but `prepareLaunch` overwrites it from the saved row before first
  paint. A regression test asserts the saved path never reaches `A4F2`.
- The reboot regression test simulates a peripheral restart with
  `FakeBleClient.simulatePeripheralRestart()`: the link stays `connected`, the
  CCCD subscriptions are gone. Recovery comes from the 110 s watchdog's
  `_resubscribeLive`, not a second timer.
