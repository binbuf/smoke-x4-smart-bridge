## Facts / gotchas for later tasks

- A config write is three GATT operations: read, write, read-back. Only the
  read-back sets `Saved`. Do not add a shortcut that trusts the write response.
- `BridgeConfigStatus` is the single branch for config refusals; the generic
  `BleFailure` mapper only recognises `0x81/0x82/0x87`. Adding `0x83–0x86` or
  133 globally would misclassify Android GATT 133.
- The review/demo path (`link == null && bleClient == null`) applies fields
  locally. Production always has a BLE client; do not use that path for real.
- Offline units are held in `_pendingUnitsWrite`, not persisted. T53 should
  persist units (and the Live change window) through `AppPreferences`.
- Schema v3 adds `preference(key, value)`. Do not create a second preference
  table; extend `AppPreferences` instead.
- The Billows screen no longer has `billows.connectionLog`; the only log is
  `bridge.connectionLog` in Bridge details.
- Smoke X4 stale copy uses `_proseDuration(age)`, so `4 min` appears only when
  the age is actually four minutes.
