## Findings

The routed findings (A–L) are in the report. The highest-impact ones are the
`Bridge A4F2` fixture leak in the offline header, the stuck
`Syncing saved readings` card while Bluetooth is blocked, the archive-wide
Cooks/sort behaviour on a full ring, the gap-band placement using
`detected_ms`, the 320 dp truncations, and the NVS-owned generation that makes
a partition erase invisible to the app's epoch logic.

## Not committed

`seeded-phone.db`, the 45 MB post-delete copy and the 6.16 MB samples-partition
backup (`34-samples-before.bin`) were bench-local and are not stored in git.
The backup metadata/hash is in `34-samples-before.sha256.txt`. Regenerate the
History fixture with `python tools/bench/t46_seed_db.py` if a later task needs
it.
